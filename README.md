# Hotz Performance — Landing Page

Landing page institucional do serviço **Hotz Performance**, de otimização de desempenho e eficiência digital.

![Prévia da landing page](docs/preview.png)

## Sobre

Site de página única com foco em conversão: proposta de valor acima da dobra, prova social e chamada para ação única (**Solicitar otimização**).

## Stack

| Camada | Tecnologia |
|---|---|
| Build | Vite |
| Estilos | Tailwind CSS + PostCSS |
| Assets | `vite-plugin-static-copy` |
| Deploy | GitHub Pages (`gh-pages`) |

## Rodar localmente

```bash
git clone https://github.com/Diegoww12a/TrindaBoost.git
cd TrindaBoost
npm install
npm run dev
```

## Build e publicação

```bash
npm run build
npm run deploy
```
